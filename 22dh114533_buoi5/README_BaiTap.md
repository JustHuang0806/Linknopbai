# SportStore — Buổi 04 và Buổi 05

Project này giữ giao diện SportStore của Buổi 04 và bổ sung phần database của Buổi 05.

- Buổi 04: trang cửa hàng, theme cam, thẻ sản phẩm và trang giới thiệu.
- Buổi 05: solution độc lập `Buoi5.sln`, EF6 kết nối SQL Server LocalDB, trang chủ đọc sản phẩm/danh mục từ database, trang `/Products` CRUD và upload ảnh. Bài tập cuối buổi bổ sung CRUD cho danh mục, khách hàng và đơn hàng.

Mở `Buoi5.sln` trong Visual Studio rồi chạy F5. Database mẫu hiện có trên `(localdb)\MSSQLLocalDB`; không chạy lại script nếu đang dùng instance này.
