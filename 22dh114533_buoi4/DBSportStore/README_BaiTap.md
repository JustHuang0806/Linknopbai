# DBSportStore – Bài tập Buổi 04 (theme cam gốc)

Chép các file này đè vào project MVC5 (.NET Framework 4.8) tên DBSportStore, đúng thư mục:

| File | Bài |
|---|---|
| Content/sportstore.css | Bài 5 (theme cam, hover, bo góc), Bài 2 (.product-description), Bài 4 (.about-card) |
| Content/images/*.jpg (8 ảnh demo) | Bài 1, 3 |
| Models/ProductCardViewModel.cs | Bài 2 (ShortDescription) |
| Controllers/StoreController.cs | Bài 1, 2, 3, 4 (8 sản phẩm + AboutStore) |
| Views/Store/Index.cshtml | Bài 2, 3 |
| Views/Store/AboutStore.cshtml | Bài 4 |
| Views/Shared/_StoreLayout.cshtml | Bài 4 (menu Giới thiệu) |
| App_Start/RouteConfig.cs | Route mặc định Store/Index |
| Bai6_GiaiThichLuongMVC.md | Bài 6 |

Sau khi chép: Visual Studio → Show All Files → chuột phải các ảnh/file mới → Include In Project → chạy (F5).
